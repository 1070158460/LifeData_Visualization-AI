# 日常使用手册

装好后（见 [SETUP.md](SETUP.md)），每天的用法就一句话：**想记什么，发给你的 bot**。

## 每天随手记（照着发就行）

| 想记什么 | 发什么给 bot | 背后发生什么 |
|---|---|---|
| 吃了什么 | `午饭 牛肉面一碗` 或 直接拍餐盘照片发过去 | 文本按常识估算/照片用视觉模型估算热量蛋白质，入 `diet.jsonl` |
| 体重 | `体重 72.5` | 入 `weight.csv` |
| 心情 | `今天有点丧` / `状态很好` | 入 `mood.csv`（1-5分） |
| 零星消费 | `打车 12块`、`奶茶 18` | 入 `transactions.csv` |
| 每月账单 | 把支付宝/微信导出的账单CSV文件直接转发 | 逐笔解析分类入 `transactions.csv` |
| 闲聊/问题 | 正常说话 | 不入库，正常回复 |

**不用记格式**，说人话就行，AI 按 [parse-rules.md](parse-rules.md) 解析；看不准的会标 `"estimate": true`，不会编数据。

## 机器人指令（随时查数据）

在聊天框输入 `/` 会弹出指令菜单，或直接发：

| 指令 | 作用 |
|---|---|
| `/today` | 今日一览：步数、最近一晚睡眠、饮食笔数与热量、支出 |
| `/week` | 最近 7 天趋势：日均步数/睡眠/热量、支出合计 + 一句观察 |
| `/report` | 立即生成昨日日报（和早上 9 点那份同款） |
| `/status` | 系统状态：各数据文件条数、手环最新样本时间、收件箱待处理数 |
| `/help` | 使用帮助 |

指令由桥（`tg_bridge.py`）直接秒回，不占收件箱、不入库。

## 每天早上 9:00 自动发生什么

1. 解析当天 inbox 里未处理的所有消息和手环数据
2. 追加写入 `data\` 各文件
3. 重新生成 `dashboard\index.html` 看板
4. 给你的 Telegram 发**日报**：昨夜睡眠、今日步数、饮食热量合计、支出合计 + 一句趋势观察（如"本周第三次睡眠不足6小时"）

电脑关机也不丢：消息在 Telegram 服务器排队，手环数据在手机里排队，开机后自动补收，当晚日报合并呈现。

## 看板

浏览器打开 `dashboard\index.html`：睡眠时长/得分、步数、支出分类环形图、每日支出、饮食热量、体重趋势。数据每晚自动更新；想立刻刷新，对 AI 说"更新看板"。

## 想问就问

数据都在本地，直接问 AI（任何接入本项目的 AI 助手）：

- "这个月外卖花了多少？"
- "最近两周睡得比上个月好吗？"
- "哪几天步数过万？"
- "帮我对比体重和睡眠的关系"

## 手环（免操作）

戴着就行。Gadgetbridge 每 3 小时自动导出 → Syncthing 自动同步进电脑。睡觉正常戴，睡眠数据次日见。

## 每月一次：账单

- 支付宝：我的 → 账单 → 右上角··· → 开具交易流水证明 → 用于个人对账 → 邮箱收CSV
- 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账
- 收到CSV → Telegram 里转发给 bot → 完事

## 数据与备份

- 所有数据在 `E:\life-os`（或你的安装目录）一个文件夹里：`inbox\`（原件）、`data\`（结构化）、`dashboard\`（可视化）
- **备份 = 把整个文件夹复制走**（或只备份 `data\`，它是纯CSV/JSONL，任何工具都能读）
- 数据只追加不修改，历史永不变化，天然可审计

## 故障速查

| 症状 | 原因与处理 |
|---|---|
| bot 不回消息 | 桥没跑（双击 `scripts\start_bridge.bat`）或代理断了（检查 Clash 类工具） |
| 手环数据没更新 | 手机上 Gadgetbridge 是否在跑、自动导出目录是否还是同步目录、手机电脑是否同一WiFi（或插USB） |
| 晚上没收到日报 | 电脑当时关机了（开机后会合并补发）或定时任务所在 AI 未运行 |
| 看板没更新 | 对 AI 说"更新看板"即可手动触发 |
